# SOC Analyst Portfolio — Genaro Scarpato

Repositorio con el análisis de casos prácticos de seguridad que fui resolviendo 
como parte de mi formación como Analista SOC Jr, usando entornos de simulación 
(LetsDefend) y laboratorios propios.

Cada caso documenta:
- Contexto y evidencia inicial de la alerta
- Reconstrucción de la cadena de ataque usando MITRE ATT&CK
- Pasos de investigación que aplicaría con acceso completo al entorno
- Clasificación (true/false positive) y respuesta recomendada
- Aprendizajes clave del caso
